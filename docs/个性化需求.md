## 一、对话内容记录功能

GIT 提交: 34a23e8b

### 需求背景

系统记录消耗日志（`logs` 表）时只包含 token 数、模型名、配额等信息，无法查看用户发送的对话内容，不便于 prompt 调试。本功能新增对话内容记录与查看能力，支持选择性开启。

### 后端变更

#### 数据库

**新增表：`conversation_records`**（存储在 `LOG_DB`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER (主键, 自增) | 记录 ID |
| `log_id` | INTEGER (索引) | 关联日志 ID |
| `user_id` | INTEGER (索引) | 用户 ID |
| `request_id` | VARCHAR(64) (索引) | 请求 ID |
| `content` | TEXT | 请求体原文（JSON） |
| `created_at` | BIGINT | 创建时间戳 |

#### 新增配置 `ConversationRecordEnabled`

- Key: `ConversationRecordEnabled`，默认 `false`
- 对应变量：`common.ConversationRecordEnabled`
- 涉及：`common/constants.go`、`model/option.go`

#### 记录逻辑

`model/log.go` → `RecordConsumeLog()`：日志写入后，若开关开启，从 gin context 读取缓存的请求体写入 `conversation_records`。仅记录 consume 类型（type=2）。

#### 新增 API 接口

| 接口 | 权限 | 说明 |
|------|------|------|
| `GET /api/log/conversation/:log_id` | AdminAuth | 根据日志 ID 查询对话内容 |
| `DELETE /api/log/conversation/?target_timestamp=xxx` | AdminAuth | 删除指定时间之前的对话记录 |

涉及：`controller/log.go`、`router/api-router.go`

#### 模型文件

`model/log_conversation.go` — `ConversationRecord` struct + `Save`/`Get`/`Delete` 函数

`model/main.go` — `migrateDB` / `migrateLOGDB` / `migrateDBFast` 新增 `&ConversationRecord{}`

### 前端变更

#### 日志设置页

`web/src/pages/Setting/Operation/SettingsLog.jsx`：
- 新增 **「启用对话消息记录」** 开关
- 新增 **「清除对话记录」** 日期选择 + 按钮

#### 日志表格

- 消费类型日志的展开详情中新增 **「对话详情」** 行（计费模式下方），点击「查看」弹窗显示 JSON 对话内容
- 仅管理员可见

涉及：
- `web/src/hooks/usage-logs/useUsageLogsData.jsx` — 展开详情条目 + `openConversationModal` 查询函数
- `web/src/components/table/usage-logs/modals/ConversationModal.jsx` — 弹窗组件
- `web/src/components/table/usage-logs/index.jsx` — Modal 渲染

## 二、回响（Echo）渠道

GIT 提交: c73f6a52, be43c370

### 需求背景

为方便测试调试，新增预制渠道类型「回响」，不调用任何 AI 服务，直接返回与输入相同的文字。

### 后端变更

#### 渠道常量

`constant/channel.go`：
- `ChannelTypeEcho = 60`
- `ChannelBaseURLs` 新增对应索引（空字符串）
- `ChannelTypeNames[ChannelTypeEcho] = "Echo"`

`constant/api_type.go`：新增 `APITypeEcho`

`common/api_type.go`：新增 `ChannelTypeEcho → APITypeEcho` 映射

#### 适配器

`relay/channel/echo/`（新包）：

| 文件 | 说明 |
|------|------|
| `constants.go` | 渠道名称 + 支持的模型列表 |
| `adaptor.go` | Echo 适配器实现 |

**工作流程：**
1. `DoRequest()` 返回 `nil`（无 HTTP 请求）
2. `DoResponse()` 从 `BodyStorage` 读取请求体，解析为 `GeneralOpenAIRequest`
3. 提取最后一条 `role: "user"` 的消息文本
4. 构建 OpenAI 格式响应，将用户文本原样返回
5. 支持流式/非流式，token 消耗计为 0

#### 注册

`relay/relay_adaptor.go`：`GetAdaptor()` 新增 `case constant.APITypeEcho: return &echo.Adaptor{}`

### 前端变更

`web/src/constants/channel.constants.js` — `CHANNEL_OPTIONS` 新增：

```js
{ value: 60, color: 'teal', label: '回响 (Echo)' }
```
